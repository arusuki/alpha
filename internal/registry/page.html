STEP 01 / 只需注册一次

准备你的登录资料

准备一个使用者标识、登录密码，以及各台电脑的 SSH 公钥。Tailscale 账号在下一步使用，与这里的账号分别登录。

以小写字母开头，3–32 位字母、数字、下划线或短横线。

12–256 字节，不能含换行或冒号。用于总控个人状态页登录，也是新建容器的初始 root 密码；领养容器保留原密码。

粘贴各台电脑的 .pub 公钥全文，一行一个，最多 64 个。注册后可在 status 状态页修改，自动同步到跳板和容器。私钥留在本机，不要粘贴到这里。

在哪里找到 SSH 公钥？

在自己的电脑打开终端（Windows 使用 PowerShell），读取已有公钥：

macOS / Linux

cat ~/.ssh/id_ed25519.pub

Windows PowerShell

Get-Content $HOME/.ssh/id_ed25519.pub

复制以 ssh-ed25519 或 ssh-rsa 开头的完整一行。若使用其他文件名，请读取对应的 .pub 文件。

还没有密钥时，可运行 ssh-keygen -t ed25519，按提示选择保存位置，再读取生成的 .pub 文件；已有密钥时不要覆盖。

    STEP 02 / 在自己的电脑上操作

    连接 Tailscale，才能进入总控

    资源就绪后，还需要你完成下面的网络连接。进度达到 100% 代表资源已分配，不代表本机 VPN 已连接。

    1

    接受分配给你的节点分享

    打开下方链接，使用自己的 Tailscale 账号登录，并接受机器分享邀请。记住使用的账号，下一步客户端要登录同一个账号。

    打开 Tailscale 分享链接 ↗

    接受成功后，页面是什么样的？

    打开 Tailscale 的 Machines 页面 ↗，查看收到的分享节点。

    Shared in
    这是别人分享给你的远程节点。
    100.x 地址
    节点的 Tailscale 地址，无需手动填进本机客户端。
    Connected
    这行远程节点在线；还要检查你自己的电脑是否已连接。
    2

    在本机安装、登录并连接

    在用于打开总控和 SSH 的电脑上，下载并安装 Tailscale ↗。打开客户端，登录刚才接受邀请的账号，并确认显示已连接（Connected）。

    macOS 从菜单栏、Windows 从系统托盘打开客户端。Linux 可在安装后运行 sudo tailscale up，按提示登录，再用 tailscale status 检查状态。

    继续前检查

    邀请已接受 → 本机使用同一账号 → 本机 Tailscale 已连接。之后访问总控或使用 SSH 时，也要保持连接。

    网页上看到分享节点，还不能代替本机客户端连接。换一台电脑使用时，也要在那台电脑安装并登录。

    STEP 03 / 以后从这里进入

    进入总控，完成最后一步

    确认本机 Tailscale 已连接后，打开你的总控个人状态页，输入刚才注册时设置的密码。无需管理员账号，也不是 Tailscale 密码。

    进入我的总控状态页 ↗

    登录成功后，请收藏总控并关闭本注册页

    以后查看容器、申请新节点的容器、获取 SSH 配置、修改登录密码，都在总控完成。无需再次注册，也无需保留注册链接。

    总控打不开，或登录失败？
    • 网页超时：检查本机 Tailscale 是否已连接，且账号与接受分享的账号一致。
    • 找不到分享节点：回到上方邀请链接确认是否接受成功；邀请失效时联系管理员。
    • 能打开但密码错误：输入 Project Alpha 注册密码，不是 Tailscale 密码。
    • 以上都正常仍打不开：把本页显示的分配错误或总控地址发给管理员核查，无需重新注册。
    进入总控前，本页可刷新恢复进度，请暂时保留当前浏览器的注册会话。登录总控后，日常操作统一在总控完成。
