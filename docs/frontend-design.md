# 总控与节点工作台

集群入口由独立总控首页提供，使用顶部导航、集群汇总与节点目录。节点卡片展示实际连通状态、容器记录数量、有容器的使用者数量、主机名和扫描任务；支持名称、主机及地址搜索，以及全部 / 在线 / 不可用筛选。整张卡片可点击，编辑、移除独立操作。不可用节点的容器及使用者数量显示为未知，部分可用或刷新失败时明确标记统计范围与旧结果。节点卡片自动刷新保留键盘焦点。

`/nodes/<id>/` 复用以下节点工作台布局，API、快照和实时事件经总控代理。节点进程本身只提供 API。集群页面与运行模式见 [集群管理](cluster.md)。

登录及恢复会话后，总控进入集群首页；点击节点才进入该节点的总面板。总面板读取轻量扫描任务状态；进入存储的空间用量页时才加载完整快照。节点顶层模块为存储、容器管理和进程管理；Agent 设置与集群使用者集中在总控，节点总面板和导航不再重复提供入口；账号管理属于平台。不可用节点点击后显示弹窗并保留当前登录状态，在线节点进入前再检查连接。扫描记录、诊断清理与扫描配置位于存储的二级导航。空间用量页将 Host 与容器 Agent 分成独立的报告入口和历史记录；当前记录没有显式 Host 扫描根时，Host 入口提示先配置并重新扫描。诊断清理仅管理员可用：上方 Host、下方容器 Agent 分别选择完整报告与提取条目，共用后续清理工作区；按四类展示可折叠表格，各类可独立按实际占用升降序排列，并支持分类筛选、搜索、勾选和删除确认；后台处理结果逐项展示，离开页面停止轮询，重新进入恢复任务。Agent 设置沿用管理员权限；只读用户可以查看存储与进程。

扫描结果 JSON 以 Blob 保存在浏览器 IndexedDB 中，按当前账号和结果地址隔离，不缓存解析后的索引。首次打开下载并保存原始结果；再次打开时，Worker 读取本地文件，使用缓存内的目录版本请求变更接口，合并新发布的目录明细与最新容器归属，并将更新后的 JSON 写回缓存。目录解析产生新版本后，关闭页面再打开也只需补齐变更，无需重新下载整份结果。认证或网络失败不会绕过校验展示缓存。缓存损坏时重新下载；缓存不可用或空间不足时仍可正常下载查看。存储模块的「本地结果缓存」展示各文件大小、总大小和删除操作；大小不含数据库开销。删除只影响浏览器缓存，并阻止删除前已开始的读取或下载重新写回缓存。

进程页面按容器显示活动进程森林，可搜索命令、PID、路径和容器 ID，并可包含宿主机。页面可见时每三秒查询现有进程 API，离开模块或退出账号时停止轮询并取消请求。连接失败时明确标注错误；保留的数据标注为上次采集结果。

总控和节点内页延续开屏的暖纸色 `#f6f5f1`、墨色 `#282a26`、朱橙色 `#b94f2e` 与鼠尾草绿。总控使用横向导航，节点工作台保留侧边导航与存储二级导航。模块入口采用细边框、小圆角、统一浅色表面与少量状态色；表格、表单、任务进度和弹窗共享配色。支持键盘焦点、移动布局及减少动画偏好。

总控示意图与节点总面板共用开屏生成的书法 α SVG 轮廓，不依赖位图或外部字体。总控圆环图为装饰示意，实际节点数量和状态以汇总、卡片为准。界面结构和交互维护在 `dist/index.html`、`dist/cluster.js`，视觉维护在 `dist/cluster.css` 和 `dist/workspace.css`。

## 登录开屏

登录页使用独立的暖纸色 `#f6f5f1`、墨色 `#282a26` 和朱橙色 `#b94f2e`，搭配细网格、坐标注记和书法 α。布局、交互分别维护在 `dist/auth.css` 和 `dist/auth.js`，不依赖图片或外部字体。

α 使用一条连续 SVG 曲线，以固定角度的宽笔尖沿轨迹构造轮廓，每帧增加已书写部分。书写 2250ms，落笔前留白 220ms，完成后停留 420ms，再用 1100ms 移至左侧并显示右侧登录面板。小屏幕将符号收至表单上方。

每次页面加载仅首次需要登录时播放；已有会话直接进入工作台，退出或会话过期直接显示表单。可以跳过、按 Escape 或重播。符号绘制期间表单使用 inert 避免键盘进入不可见控件，面板开始出现即允许输入；减少动态效果时直接呈现完成布局，标签页隐藏时结束动画。初始化管理员、输入校验和后端错误沿用现有认证接口。
